# Virago - E-Commerce Website

A modern, responsive e-commerce platform built with HTML, CSS, and JavaScript. 

## Features

- **Product Shop** - Browse and explore a wide range of products
- **Shopping Cart** - Add items to cart and manage purchases
- **Blog Section** - Read the latest updates and product articles
- **Responsive Design** - Fully optimized for mobile, tablet, and desktop devices
- **Mobile Navigation** - Hamburger menu for easy navigation on smaller screens
- **Product Details** - Individual product pages with detailed information
- **Contact & About** - Pages for customer inquiries and company information

## Pages Included

- Home Page (index.html)
- Shop Page (shop.html)
- Individual Product Page (sproduct.html)
- Blog Page (blog.html)
- About Page (about.html)
- Contact Page (contact.html)
- Shopping Cart (cart.html)

## Technologies Used

- **HTML5** - Structure and markup
- **CSS3** - Styling and responsive design
- **JavaScript** - Interactive features and navigation

## Features

- Free shipping promotion
- Online order functionality
- Mobile-first responsive design
- Interactive shopping experience
- Clean and modern UI

## Getting Started

Simply open `index.html` in your web browser to explore the site.
